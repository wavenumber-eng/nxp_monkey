nxp_monkey.source_lock

design / api / source_lock

SourceLockError

Kind: exception.

Reports fail-closed source resolution and replay errors.

resolve_source_lock

Kind: function.

Resolves a pinned official manifest, board closure, exact selected commits, reviewed consumed files, and license evidence into canonical source-lock v0 JSON. The function writes only the requested output and reusable Git and policy cache objects.

verify_source_lock

Kind: function.

Recomputes source-lock identity and verifies all retained Git objects, blobs, and license policy bytes. V0 requires explicit offline mode and never repairs or fetches a missing cache object.
