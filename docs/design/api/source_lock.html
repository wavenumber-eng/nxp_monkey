nxp_monkey.source_lock

design / api / source_lock

SourceLockError

Kind: exception.

Reports fail-closed source resolution and replay errors.

resolve_source_lock

Kind: function.

Resolves a pinned official manifest, board closure, exact selected identities, reviewed consumed files, and license evidence into canonical source-lock v0 JSON. Only repositories containing consumed files are downloaded. The function writes only the requested output and reusable Git and policy cache objects.

verify_source_lock

Kind: function.

Recomputes source-lock identity; binds the cached profile, replayed west inventory/selection, closures, licenses, and imports; and verifies all retained Git objects, blobs, and license policy bytes. V0 requires explicit network-guarded offline mode and never repairs or fetches a missing object.
