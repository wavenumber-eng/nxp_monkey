Portable model API

ModelError is the fail-closed error type.

KexModelError is the fail-closed KEX model-v2 error type.

normalize_model builds canonical model-v1 JSON from a verified offline source lock.

normalize_kex_model builds canonical model-v2 JSON from a verified KEX acquisition lock, requires the explicitly accepted lock identity and exact generator Git revision, expands register templates, retains complete package/pin routes and package-specific declarations, and emits source-level subtree provenance.

verify_kex_model validates an existing model-v2 file against its schema, content identity, provenance coverage, and semantic invariants and returns the validated model. It does not re-read the original KEX cache; acquisition-lock verification and normalization validate the consumed source bytes.

compare_models emits stable semantic differences and coverage counts.

validate_model_semantics checks identities, hashes, references, and leaf provenance.
