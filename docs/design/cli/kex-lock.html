nxp-monkey kex-lock

Purpose

Create and offline-verify deterministic acquisition locks for explicitly authorized KEX inputs.

nxp-monkey kex-lock create --part MCXA156 --upstream-version 26.06 \
  --variant ksdk2_0 --variant zephyr3_2 --producer-revision COMMIT \
  --cache CACHE --output LOCK.json
nxp-monkey kex-lock verify --lock LOCK.json --cache CACHE --offline

The lock binds retained upstream archives, the complete extracted file closure, XML namespace and schema-location identities, and regenerated lossless JSON mirror hashes. Host paths are represented by placeholders. Verification never downloads or repairs content.
