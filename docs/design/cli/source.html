nxp-monkey source

design / cli / source

Purpose

Resolve an exact official MCUXpresso west manifest and verify immutable source locks. Source-lock v0 accepts only open, reviewed Git inputs and records KEX as not-used.

Usage

nxp-monkey source resolve \
  --manifest-url URL --manifest-revision COMMIT \
  --board BOARD --device DEVICE --profile-spec PROFILE.json \
  --resolver-revision COMMIT --kex-policy not-used \
  --cache CACHE --output LOCK.json

nxp-monkey source verify --lock LOCK.json --cache CACHE --offline

Resolution contract

The manifest and resolver revisions must be lowercase 40-hex commits. west 1.5.0 parses imports, and the pinned manifest's update_board --list-repo command selects the board closure. The resolver records all manifest projects, including explicitly unavailable inactive projects, while downloading only repositories that contain profile-declared consumed files with an allowed cache disposition. A reviewed profile can add exact optional manifest projects and names the smaller file-level consumed closure and its license dispositions.

Because every active project in the supported baseline already has an exact revision, west manifest --resolve --active-only is the v0 frozen-manifest oracle. A moving active revision is rejected unless it can first be resolved to an exact commit; the retained project records are always exact.

Offline verification

Verification requires --offline. It recomputes the lock ID, embedded-output hashes, manifest/import/board blobs, the cached profile, every consumed commit/file, and the retained license policy. It derives the full project inventory and both closures again from west and requires exact equality with the lock. Git lazy fetching is disabled, Python DNS/socket calls are denied, and west-extension child processes are restricted to local Git/Python operations, so a missing object fails rather than reaching the network.

Determinism

Host paths use ${CACHE}, ${PROFILE}, ${LOCK}, and ${OUTPUT} in the recorded command. Canonical JSON contains no timestamps or temporary paths. Independent clean caches must produce byte-identical locks.
