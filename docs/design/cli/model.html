model

model normalize verifies a retained source lock and cache with networking disabled, consumes only the lock-declared files, and writes a canonical portable model. --offline is mandatory.

model normalize-kex verifies a KEX acquisition lock offline and writes normalized-model v2. It consumes the locked KEX XML as hardware authority, expands register templates, catalogs package pin routes without duplication, preserves package-specific declarations and clock/resource documents, and records compact source-level provenance for every fact subtree. --accepted-lock-id must exactly match the verified lock and --generator-revision must be a full 40-hex commit; both values are embedded in the artifact contract.

model compare compares portable model JSON, supported nxp-pac adapter metadata, or a generated nxp-pac Rust module and writes stable findings plus category coverage. A difference is never silently discarded: it is either unresolved or explicitly classified as a v0-scope/derivative-only fact.
