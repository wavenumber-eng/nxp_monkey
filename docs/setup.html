Setup

NXP Monkey uses uv, Hatchling, Rack, pytest, ruff, pyright, build, and twine.

Required Tools

  • Python 3.12, 3.13, or 3.14
  • uv 0.13.4 or newer
  • Git

Development Commands

uv sync --all-extras
uv run nxp-monkey --version
uv run nxp-monkey version
uv run rack run --all
uv run python -m build --installer uv
uv run twine check dist/*
uv run python tests/support_scripts/install_test.py

Certificate Trust

Runtime KEX connections use Certifi 2026.10.19 or newer with certificate and hostname verification enabled. Keep the host OS trust store current for other tools. Use pip 26.2.2 or newer wherever pip is installed; follow the checksum-pinned bootstrap in the incident notice when starting from an affected installer. Package builds use --installer uv; installed-wheel tests use uv and do not seed pip. See the 2026.10.22 release notes for runtime trust-policy compatibility details.

Release

Release publication validates the package and publishes through PyPI trusted publishing. Do not use local PyPI tokens for the normal release path.

Binary Distribution Policy

This release is pure Python. Future native, CLI-bundle, or WebAssembly artifacts should be separated by platform and architecture using directories such as dist/native/windows-x64/, dist/native/linux-x64/, dist/native/macos-arm64/, and dist/wasm/browser/.
