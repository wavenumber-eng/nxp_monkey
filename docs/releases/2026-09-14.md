# NXP Monkey Release 2026-09-14

## [2026.9.14]

Release `2026.9.14` widens the supported Python range so the tool installs on
current Wavenumber workspaces.

Highlights:

- Support Python 3.12 through 3.14. The previous `>=3.12,<3.13` requirement
  blocked `uv tool install` on workspaces that default to Python 3.14.
- Exercise Python 3.12, 3.13, and 3.14 in CI on Linux, macOS, and Windows.
- Keep public command names, cache layout, JSON sidecars, and the Python API
  unchanged.
